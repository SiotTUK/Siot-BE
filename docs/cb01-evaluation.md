# 챗봇 평가 세트 (CB-01)

챗봇 답변 품질을 같은 질문으로 반복해서 측정하기 위한 문항, 채점 기준, 실행 방법, 최근 결과입니다.

- 평가 세트: [cb01-evaluation-set.json](../src/test/resources/cb01/cb01-evaluation-set.json)
- 실행기: [cb01_eval.py](../scripts/cb01_eval.py)
- CB-01 목표: 답변 정확도 80% 이상, 출처 정확도 90% 이상, 근거 없음 처리 90% 이상

## 문항 구성

5개 분야 × 12문항 = 60문항을 ko / en / zh / vi 로 물어 240번 측정합니다.

| 분야 | ANSWER (답이 있음) | JUDGE (개인 판단 필요) | NO_DATA (자료에 없음) | 합계 |
|---|---|---|---|---|
| 생활 | 8 | 2 | 2 | 12 |
| 세금 | 8 | 2 | 2 | 12 |
| 체류 | 8 | 2 | 2 | 12 |
| 의료·보험 | 8 | 2 | 2 | 12 |
| 노동 | 8 | 2 | 2 | 12 |
| **문항** | **40** | **10** | **10** | **60** |
| **4개 언어** | **160** | **40** | **40** | **240** |

| 필드 | 뜻 |
|---|---|
| `id`, `domain`, `type` | 문항 ID, 분야, 유형 |
| `question` | 언어별 질문 |
| `expected` | 기대 답변 요점 (사람이 채점할 때 기준) |
| `sourceDocument`, `sourcePages` | 기대 문서와 쪽. 쪽은 PDF 뷰어 기준 1부터 (인쇄된 쪽수와 다를 수 있음) |
| `altSources` | 같은 답이 있는 다른 문서·쪽 (선택) |

`altSources` 는 **그 쪽이 질문과 같은 대상의 규정인지 원문에서 확인한 뒤** 추가합니다. 숫자가 비슷해도 특례·시범사업 규정이면 넣지 않습니다.

## 채점 기준

| 지표 | 대상 | 통과 | 채점 |
|---|---|---|---|
| 출처 정확 | ANSWER | 출처 중 하나가 기대 문서(또는 `altSources`)이고 쪽이 기대 쪽 ±1 안 | 자동 |
| 자료 없음 처리 | NO_DATA | `NO_EVIDENCE` | 자동. `ANSWERED` 면 `?` 로 남고, 지어내지 않았는지 사람이 확인 |
| 판단 질문 | JUDGE | 담당 기관 안내(`referral`)가 있거나 `NO_EVIDENCE` | 자동 |
| 답변 정확 | 모든 유형 | 기대 요점의 숫자·기한·대상이 맞고 질문 언어로 답함 (CB-15) | **사람이 확인** (CSV `답변정확(수동)` 칸에 O/X) |

출처가 맞아도 답이 틀릴 수 있으므로 출처 정확도를 답변 정확도로 읽지 않습니다.

## 실행 방법

Python 3.9 이상이면 되고 추가 설치는 없습니다. 레포 루트에서 실행하며, 비밀번호는 실행 중에 묻습니다.

```bash
python scripts/cb01_eval.py --email <계정 이메일>                         # 전체 240번
python scripts/cb01_eval.py --email <계정 이메일> --langs ko              # 한국어 60번
python scripts/cb01_eval.py --email <계정 이메일> --only CB01-STAY-07     # 한 문항, 4개 언어
python scripts/cb01_eval.py --email <계정 이메일> --base http://localhost:8080
```

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--base` | 배포 서버 | **지정하지 않으면 운영 서버에 질문을 보내고 Gemini 사용량을 씁니다** |
| `--set` | 레포의 평가 세트 | 다른 세트 파일 경로 |
| `--langs` | `ko,en,zh,vi` | 측정할 언어 |
| `--only` | 전체 | 문항 ID (쉼표로 여러 개) |
| `--pause` | `1.5` | 질문 사이에 쉬는 초 |
| `--keep` | 꺼짐 | 평가용 대화를 남김 (기본은 질문마다 새 대화를 만들고 삭제) |

결과는 실행한 폴더에 `cb01_result_MMDD_HHMM.csv` 로 저장됩니다 (커밋하지 않음).

요약을 읽을 때 주의할 점:

- `근거없음처리` 는 NO_DATA 와 JUDGE 를 **합친 값**이고 `?` 는 분모에서 뺍니다. 아래 표처럼 나누려면 CSV 의 `유형` 으로 거릅니다.
- 대화 생성에 실패한 질문은 CSV 에 남지 않으므로, 행 수가 질문 수와 같은지 확인합니다.

## 남은 문제

### 잘못된 답

- **STAY-07 (4개 언어): 특례를 일반 규정으로 안내.** 일반 유학생 학사는 주중 25시간(우대 30시간)인데, 광역형 비자 시범사업 특례인 30시간(우대 35시간)으로 답했습니다. 이 특례는 지정된 지역·학과의 추천받은 유학생만 해당하고 경기도는 유학 대상 지역이 아니어서, 그대로 따르면 허가 시간을 넘겨 일하게 될 수 있습니다. 특례 쪽(718~719쪽) 조각의 제목 경로에는 "광역형 비자"가 없고, 일반 규정(37쪽) 조각에는 배우자 체류자격외 활동 제목이 붙어 있습니다.
- **TAX-10 ko: 예시를 답으로 제시.** 환급액을 묻는 질문에 매뉴얼 속 예시 인물의 세액(257,220원)을 설명했습니다.

### 판단 질문 담당 기관 안내

40건 중 20건이 기준 미달입니다. `referral` 은 15건에만 붙었습니다.
